# CareerGenie
IIT Patna Capstone Project

### **Career Genie** 
From “I want this job” to “I’m ready for the interview.” 

**AI-POWERED CAREER APPLICATION & INTERVIEW PREPARATION ASSISTANT** 

 
THE VISION  —  Career Genie connects the complete job-seeker journey — job analysis, role-specific CV improvement, skill-gap discovery, 
application tracking and interview preparation — in one continuous, role-specific workflow app. 
 
**PROBLEM** 
Professionals reuse a generic CV across different jobs, even though 
employers screen for role-specific keywords. Candidates can't tell why a CV 
doesn't match, which skills are missing, which version was sent, or how to 
prepare for the interview — tailoring, tracking, upskilling and interview 
prep stay fragmented across separate tools. 


**PROPOSED SOLUTION** 
Career Genie analyses a target job (description or URL) against the 
candidate's CV, highlights strengths and gaps, and recommends explainable 
edits the candidate accepts or rejects before exporting a tailored CV. The 
same job–CV pairing then generates interview questions, runs a text-based 
mock interview, and gives AI feedback — context is never re-entered. 
 
Not just a CV generator or a generic interview chatbot. Career Genie keeps one shared context across job, CV, skills and interview prep, with explainable, candidate-controlled recommendations. 
 
CORE FEATURES — MVP 

>Job Specification (JD) Input 
   Paste a job description or URL 
>CV Upload & Parsing 
   Extract experience, skills & achievements 
>Job–CV Match Analysis 
  Gaps, keywords & match score 
>Explainable Recommendations 
  Targeted visual edits with reasoning 
>Accept / Reject Changes 
   Candidate controls every edit 
>Tailored CV Export 
  Per application, or send by mail app 
>Application Tracker 
  Job, employer, date & CV version 
>Interview Intelligence 
  Role-specific mock interview + feedback 

 
**TARGET USERS** 
Professionals seeking a new job, promotion or career pivot — especially experienced IT/tech, finance, consulting and management/executive candidates. 


**TOOLS, TECHNOLOGY & DATA** 
OpenAI/Claude for analysis & interview intelligence · Supabase for backend database, Google Cloud for storage· Lovable/ Replit /Next.js for frontend MVP · PDF/DOCX OCR, parsing & visual CV editor, N8N for automation. 

**EXPECTED OUTCOME** 
A working prototype helping candidates target the right roles, submit better matched CVs, close skill gaps, and practise for likely interviews. 
 
Target Job  →  CV Analysis  →  Skill Gaps  →  CV Improvement  →  Tailored CV  →  Track Applied CV   
→  Interview Prep  →  Mock Interview  →  Feedback 
 
Roadmap (post-capstone): voice-based mock interviews · record real live interviews using AI assistant, personalised upskilling 
recommendations · automated job-URL application integration · recruiter-facing discovery view.
